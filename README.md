# gitWIKI - Gerência de Configuração e Mudanças
Um mini-site documentativo sobre comandos Git como uma wiki, desenvolvido como parte do projeto de Gerência de Configuração e Mudanças no curso de Análise e Desenvolvimento de Sistemas do IFPB.

## Objetivo
Este repositório tem por objetivo centralizar código, documentação e artefatos relacionados ao projeto de Gerência de Configuração e Mudanças, desenvolvido no âmbito do curso de Análise e Desenvolvimento de Sistemas do IFPB.
